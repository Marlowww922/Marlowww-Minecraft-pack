# Marlowww-Minecraft-pack
Marlowwww's Minecraft mod pack (all mods) 
To use this mod correctly you, have to Open up Minecarft java edition (Marlowww Java.zip) - file, and then click on options and then resource pack and then upload this zip file (Marlowwww Java.zip)
For Bedrock players - Download this Mod and then open up files (Android or IOS) and then double click on the file (Marlowww bedrock.mcpack)
and it will open up Minecraft and enjoy the mod! (Or just click on the three dots on the top right after you click on the file once and select Minecraft)
